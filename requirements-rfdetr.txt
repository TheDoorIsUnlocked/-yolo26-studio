# =============================================================
# !! 装完必做：修复被 roboflow 顶掉的 cv2 !!
# -------------------------------------------------------------
# 坑：roboflow 依赖 opencv-python-headless，它和项目在用的
#     opencv-python 抢同一个 cv2 模块，且会被装成 5.0.x（大版本跳跃，
#     有破坏性 API 变更）。装完 rfdetr 后 cv2 会变成 headless 5.0。
#
# 验证：python -c "import cv2; print(cv2.__version__)"
#       期望 4.12.0.88；若显示 5.0.0 说明被顶掉，执行下面两条修复：
#
#       pip uninstall -y opencv-python-headless
#       pip install --force-reinstall --no-deps opencv-python==4.12.0.88
#
# 说明：卸载 headless 只影响 roboflow 的「从云端下载数据集」功能，
#       我们用本地 YOLO 数据集（dataset_file="yolo"），完全用不到。
# =============================================================

# =============================================================
# !! 权重下载：默认落在 C 盘，且国内速度极慢 !!
# -------------------------------------------------------------
# RF-DETR 首次实例化模型会自动下载预训练权重，默认缓存到
#   C:\Users\<用户名>\.roboflow\models\
# 两个问题：
#   1) 占 C 盘。Nano 权重 349MB，Small/Medium 更大。
#   2) 源是 storage.googleapis.com，国内实测单线程仅 ~230KB/s，
#      RF-DETR 自带下载器更慢（50~90KB/s），349MB 要下 1 小时以上。
#
# 解决办法（本项目已在代码里内置）：
#   * 设置环境变量 RF_HOME 把缓存重定向到项目所在盘：
#       set RF_HOME=E:\rfdetr_models
#     代码见 rfdetr_adapter.ensure_rf_home()，默认指向 <项目根>/.rfdetr_models
#   * 用多线程分块下载器预取权重（8 线程可到 2.5MB/s 起步）：
#       python dl_weight.py nano
#     下载到 RF_HOME 目录并保持文件名 rf-detr-nano.pth，
#     之后实例化会校验 MD5 并跳过下载。
#
# 权重 URL 与文件名映射（rfdetr/assets/model_weights.py）：
#   nano   -> rf-detr-nano.pth    <- .../nano_coco/checkpoint_best_regular.pth
#   small  -> rf-detr-small.pth   <- .../small_coco/checkpoint_best_regular.pth
#   medium -> rf-detr-medium.pth  <- .../medium_coco/checkpoint_best_regular.pth
# =============================================================
